# LocalHelm

**Status for the products you ship.**

A named fleet of local repos: git, npm, dependents, and the public shelf, in one place. Pairing: **LocalBerth** is the slip; **LocalHelm** is the wheel.

This repo is at genesis. The build spec is [`docs/GENESIS.md`](docs/GENESIS.md). `package.json` is `localhelm@0.0.0` so the name can be reserved on npm; there is no usable CLI yet.
